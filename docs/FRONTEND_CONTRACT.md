# FRONTEND CONTRACT SPECIFICATION — ACDS

**Project**: Adaptive Cyber Defense System for SMEs (ACDS)  
**Document**: Frontend-to-Backend Interface Contract & Non-Regression Specification

---

## 1. Absolute Preservation Directives

The existing Streamlit user interface is **APPROVED and LOCKED**.
Backend modularization, refactoring, and algorithm enhancements must adhere 100% to this contract.

1. **No visual redesign**: The layout, cyberpunk HUD theme, colors (`#050a0f`, `#00d4ff`, `#ff3355`, `#00ff88`, `#ffd700`, `#ff8c00`), fonts (Orbitron, Share Tech Mono, Rajdhani), cards, and expanders must not be changed.
2. **No framework replacement**: Streamlit and PyVis must remain the UI and visualization frameworks.
3. **Session state stability**: All `st.session_state` keys and types must remain available and populated with expected structures.
4. **Graph model compatibility**: The NetworkX graph `G` remains the authoritative visual representation; node and edge attribute schemas must be preserved.

---

## 2. Session State Contract (`st.session_state`)

| Key | Type | Default Value | Description / Consumer in UI |
|---|---|---|---|
| `network_mode` | `str` | `"Real Network Scan"` (or `"Simulated Lab"`) | Active network operational mode selector in the sidebar radio button. |
| `G` | `networkx.DiGraph` | `build_network()` or `nx.DiGraph()` | Authoritative network graph storing all node/edge attributes for PyVis visualization and node intelligence panels. |
| `simulation_done` | `bool` | `False` | Flag indicating whether attack simulation has run. Controls conditional rendering of post-simulation panels. |
| `timeline` | `List[Dict[str, Any]]` | `[]` | Sequential list of simulation step dictionaries (`timestep`, `node`, `from_node`, `mitre_code`, `mitre_desc`, `access_vector`, `success`, `vuln`, `criticality`, `ntype`, `priv_esc`). |
| `compromised` | `Set[str]` | `set()` | Set of node identifiers currently compromised in the simulation. |
| `risk_score` | `float` | `0.0` | Active blast radius risk score ($0.0 - 100.0$) displayed in HUD metric cards and blast radius panel. |
| `blast_details` | `Dict[str, Any]` | `{}` | Detailed blast radius metrics (`spread`, `critical_impact`, `depth`, `compromised_count`, `total_real_nodes`, `systems_controlled`, `max_lateral_hops`, `privilege_escalations`, `critical_assets_reached`, `attack_paths`). |
| `honeypot_triggered` | `bool` | `False` | Flag indicating whether simulated attack traversed a honeypot node. Displays honeypot alert banner. |
| `defense_actions` | `List[Dict[str, Any]]` | `[]` | List of candidate defense actions generated by the optimization engine. |
| `selected_defenses` | `List[Dict[str, Any]]` | `[]` | Defenses selected by the greedy knapsack optimizer within budget constraints. |
| `applied_defenses` | `List[Dict[str, Any]]` | `[]` | Defenses applied to the graph model. Used to show post-defense stats. |
| `ids_deployed` | `bool` | `False` | Flag indicating whether global IDS/SIEM defense is active in simulation. |
| `segmentation_applied` | `bool` | `False` | Flag indicating whether VLAN segmentation is active in simulation. |
| `attack_log` | `List[Dict[str, Any]]` | `[]` | Formatted event log entries (`src`, `target`, `action`, `technique`, `reason`, `status`, `severity`). |
| `attack_stats` | `Dict[str, Any]` | `{}` | Summary statistics from attack simulator. |
| `current_anim_node` | `Optional[str]` | `None` | Active node being highlighted during the step-by-step UI animation loop. |
| `last_scan_devices` | `Optional[List[Tuple]]` | `None` | Raw device discovery tuples from last network scan. |
| `scan_started_at` | `Optional[datetime]` | `None` | Timestamp of scan initiation. |
| `scan_completed_at` | `Optional[datetime]` | `None` | Timestamp of scan completion. |
| `scan_error` | `Optional[str]` | `None` | Error message string if network scan failed safely. |
| `scan_timeline` | `List[Dict[str, Any]]` | `[]` | List of actual executed scan events (`timestamp`, `event`, `target`, `status`). |
| `scan_history` | `List[Dict[str, Any]]` | `[]` | Session scan audit history list (`scan_id`, `timestamp`, `scan_type`, `asset_count`, `average_risk`, `critical_count`, `high_count`, `medium_count`, `low_count`). |
| `scan_counter` | `int` | `0` | Monotonically increasing scan counter. |
| `risk_before_defense` | `Optional[float]` | `None` | Baseline blast radius risk score before defenses were applied (for Before-vs-After diffs). |
| `blast_before_defense`| `Dict[str, Any]` | `{}` | Baseline blast details before defenses were applied. |
| `post_defense_stats` | `Optional[Dict[str, Any]]` | `None` | Blast details after defense application and re-simulation. |
| `overall_acds_risk` | `Optional[Dict[str, Any]]` | `None` | Synthesized 60/40 risk dictionary (`status`, `overall_score`, `severity`, `asset_component`, `asset_weight`, `blast_component`, `blast_weight`). |
| `budget` | `int` | `50` | Slider state for defense budget. |

| `os_evidence` | `List[str]` | `["TTL=64 suggests Linux"]` | Evidence trail bullet points. |
| `device_type` | `str` | `"Web Server"` / `"Mobile Device"` | Device type label and icon. |
| `device_confidence`| `Optional[float]` | `0.85` | Device classification confidence. |

| `risk_components` | `Dict[str, Dict]` | Breakdown dict | 5-component breakdown bar ($40/20/15/15/10$). |
| `cve_findings` | `List[Dict]` | List of CVE dicts | Red box list of confirmed CVEs. |
| `exposure_findings`| `List[Dict]` | List of exposure dicts | Amber box for unversioned exposures. |

| `node_type` | `str` | `"endpoint"`, `"server"`, `"database"`, `"honeypot"`, `"perimeter"` | PyVis node shape (`dot`, `square`, `database`, `star`, `diamond`). |
| `compromised` | `bool` | `False` | Red color toggle in graph and card. |
| `priv_escalated` | `bool` | `False` | Privilege escalation status tag. |
| `isolated` | `bool` | `False` | Green color toggle in graph and card. |

## 5. Compatibility & Refactoring Strategy

To maintain 100% UI stability during modularization:
- The modular package `acds/` will implement pure, decoupled business logic, data models, simulation engines, adaptive honeypot feedback, persistence, and experimentation.
- `app.py` will import these modular components while preserving all existing Streamlit UI code, session state initialization, visual components, and styling.
- Any wrapper functions required for legacy compatibility will be maintained so that zero breaking changes occur.
